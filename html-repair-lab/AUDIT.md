Problem 1
Problem: A heading tag is in the "head" part of the html file.
Fix: Moved it to the body.
Why: A heading is meant to be displayed and it in the head part of the file doesn't achieve this purpose.

Problem 2
Problem: There was no doctype
Fix: I added a Doctype
Why: So the browser can know which version of HTML the page is written in and so it can act accordingly.

Problem 3
Problem: The was no specified primary language
Fix: I added a lang="en" to the html opening tag
Why: So the browser will know the primary language of the webpage

Problem 4
Problem: The nav links are in a div tag
Fix: Put them in a nav tag
Why: The div tag doesn't provide any semantic meaning that'll show that the links enclosed in it are navigation links

Problem 5

Why: It boils down to semantics as it allows screen readers understand the layout.
